About the project

How Bharat Darshan works

A small, static website that puts India's heritage sites on a map, tells their story in five stages, and keeps every fact next to the source it came from.

What you can do here

Open the map, filter by region or building type, and click a pin. Each site opens a detail page with its history, quick facts, official UNESCO and Archaeological Survey of India links, and a set of sources you can check yourself.

Add up to five stops to a journey and the page works out a rough straight-line distance between them. Earn badges as you explore. Switch the interface to Hindi. None of it needs an account.

The rule we followed
If a feature needed an API key, a login, a paid service, or a file we did not have, it was cut. Everything on this site runs from files in the repository.

Architecture

How the pieces fit

Plain HTML, CSS and JavaScript. No framework, no bundler, no build step — open the file index.html and it runs.

One data file

Every page reads the same array of sites, so a fact written once appears everywhere and cannot drift apart.

No backend

There is no server to hack, no keys to leak and no database to break. Your saved journey never leaves the device.

Everything local

Libraries and images live in the repository, so the site still works when the wifi does not.

Verification

Where the facts came from

Each site's detail page lists its own sources. These are the standing references the whole project relies on.

    What we deliberately did not do
    • No invented dates, numbers or quotes. Anything we could not verify is marked “TODO” instead of filled in.
    • No invented transcriptions. The Persian verse in the Manuscript Lens is translated by the museum, not by us.
    • No UNESCO or ASI claim without a link to the page that makes it.
    • No “recommended for you” or “related sites” sections — the map shows what the filters ask for, nothing more.
    Setup

    Run it yourself

    1. Clone or download the repository.
    2. Double-click the file index.html. That is the whole setup — there is nothing to install.
    3. Optional: serve the folder with any static server, for example python -m http.server 8000, then open http://localhost:8000.
    4. To deploy, push the folder to GitHub Pages or drag it into Netlify. No build command.

    Tested in current Chrome, Edge and Firefox on desktop, and in mobile Chrome and Safari.
